Google Apps Script 設定教學與腳本程式碼

1 設定 Google Sheet 步驟：

  1. 打開你的 Google Sheet 試算表。
  2. 點擊頂部選單的 「擴充功能 (Extensions)」 ➔ 「Apps Script」。
  3. 清空裡面的原始碼，貼上右側/下方的腳本程式碼，並按下 儲存 (⌘+S / Ctrl+S)。
  4. 點擊右上角 「部署 (Deploy)」 ➔ 「新增部署 (New deployment)」。
  5. 選擇類型 「Web 應用程式 (Web app)」。
  6. 將「誰有權存取 (Who has access)」設定為 「所有人 (Anyone)」，然後點擊「部署」。
  7. 複製生成的 Web App URL，貼回本系統的「Google Apps Script Web App 連結」輸入框即可！
